# Data Extracted from Kew World Checklist of Vascular Plants (WCVP)

WCVP is the data source that powers much of the Kew Plants of the World Online. A version of the data is available for download from this URL.

http://sftp.kew.org/pub/data-repositories/WCVP/wcvp.zip

As of 2026 WFO have maintained a name matched version of this file for several years that we use to update our classification in areas not covered by Taxonomic Expert Networks.

Here we extract some faceting data from the WCVP as CSV files that can act as data sources for the WFO portal.

The scripts here should be thought of as only informative as they depend on a MySQL instance available that contains the name matched version of the WCVP file that will not be updated in the future. 

Ideally, future versions of these CSV files should generated directly by the new system used to curator the data.
