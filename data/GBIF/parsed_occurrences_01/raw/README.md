# Raw data from figshare

The data is far too large to include in github.

Download it from https://figshare.com/ndownloader/files/49459674 It is 3.57 GB.

It isn't zipped up so zip it up and save your hard drive. It should go down to 730 MB. The scripts can read the data from the zip file.

Delete the parseGBIF_useable_rechecked_successfully_plus.csv file

If you rename the parseGBIF_useable_rechecked_successfully_plus.csv.zip then make sure you add the new file to .gitignore or you won't be able to push the next commit to github.

wcvp_to_wfo_map.csv.zip is a mapping file extracted from the WCVP dump table that was used for this analysis which should make it possible to recreate if needed and the WCVP dump of January 2026 is not available.

The files in the country_files folder are the polygons used for the countries.
