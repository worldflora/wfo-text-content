## Flora d'Afrique

Supplied by Meise Botanic Garden (Belgium) through their African Flora projects. The data is in French where applicable, however the vernacular data includes ~44 languages.

Some rows in the vernacular data contain only a single colloquial term with an ISO language code in separate, corresponding columns, but many rows lack a single ISO code because they contain a description with multiple vernacular terms in multiple languages. Will work on (as of 8/9/26) separating these into their own individual rows with the corresponding ISO codes to complete the data for uploading into Fyllo.

raw - folder has the data as supplied with WFO ID field added.
out - separated into files for the snippet server. Snippet sources include conservation, distribution, habitat, morphology, use and vernacular.
