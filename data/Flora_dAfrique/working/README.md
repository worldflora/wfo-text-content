There are two main issues that can be resolved by the data provider. Attempting to resolve them on our end may lead to inaccurate data.

For context, the data that is formatted correctly and is theoretically ready to be uploaded to Fyllo (416 rows) involve individual rows containing a single vernacular term and it's associated ISO 630 code (in their respective columns), including the undetermined "und" code. The problematic rows deviate from this structure as follows:

1. 107 rows possess individual vernacular names without an ISO code (the cell in the language column is blank).

2. 529 rows possess descriptions in the vernacularName column containing two or more vernacular names of different languages, regions or tribes. They contain no ISO codes.
